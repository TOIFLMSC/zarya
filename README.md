# Заря

Telegram-бот с настраиваемым характером и локальной панелью управления.
Основной код — Python; браузерный интерфейс — React/TypeScript.

Репозиторий содержит приложение и **нейтральный пример** промптов. Рабочий характер,
полные инструкции, настройки владельца, переписки, память, ключи и медиа сюда не входят.

## Возможности

- Личные диалоги после одобрения заявки `/start`, отдельные разрешения для групп.
- Ответы на имя, упоминания и реплаи; индикатор набора и отправка частями.
- Фото, альбомы, стикеры, доступные аватарки по запросу.
- Голосовые и короткие Telegram-видео, GIF и кружочки: речь и выбранные кадры.
- Разбор ссылок и пересланных постов, поиск и фактчек; текстовые данные YouTube.
- Контекст, профили собеседников, сводки и управляемое разделение памяти между чатами.
- Настроение, реакции, настраиваемая вероятность самостоятельного участия.
- Журнал операций, версии настроек, расходы, задержки и тестовые прогоны.
- Офлайн-резервирование и проверяемое восстановление в карантин.

## Быстрый старт

Нужны Python 3.12, uv, Node.js 24 и pnpm 11.19.0. Зависимости закреплены в lock-файлах.
Выполняйте из корня проекта (PowerShell):

```powershell
uv sync --frozen
New-Item -ItemType Directory -Force data | Out-Null
if (-not (Test-Path -LiteralPath data/prompts.json)) {
    Copy-Item src/zarya/prompts.example.json data/prompts.json
}
Set-Location web
pnpm install --frozen-lockfile
pnpm run build
Set-Location ..
uv run --frozen zarya
```

Копируйте пример только в **новую установку**. Не перезаписывайте действующий
`data/prompts.json`: он содержит вашу собственную конфигурацию.

Откройте http://127.0.0.1:8787. На первом запуске используйте локальный
`data/bootstrap-token.txt`, затем задайте пароль администратора. Для подключения
бота сохраните токен в `data/telegram-token.txt`, ключ OpenAI — в
`data/openai-api-key.txt`, перезапустите приложение. Без ключей панель доступна,
внешние клиенты выключены. Файлы секретов не нужно отправлять в чат или Git.

Для FFmpeg и подробной настройки смотрите [установку](docs/setup.md).

## Ограничения

Видео анализируется по выборке кадров и доступной речи, поэтому быстрые события
могут быть пропущены. YouTube-метаданные и субтитры не означают просмотр видеоряда;
доступ к ним зависит от внешнего сервиса. Аватарки ограничены тем, что отдаёт Telegram.
Ответы модели и извлечённые факты могут ошибаться и требуют проверки.
Доступность выбранных моделей определяется вашим API-аккаунтом.

Это локальная версия: сервер слушает loopback, рассчитан на один процесс и одного
получателя Telegram-обновлений. Защищённый VPS-деплой требует отдельной подготовки;
не публикуйте локальный HTTP-интерфейс напрямую в интернет.
