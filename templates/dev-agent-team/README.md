# Команда разработки Codex 0.1.0

Этот комплект переносит роли и маршрутизацию из Зари в существующий репозиторий.
Он подходит проектам на разных стеках и сохраняет локальные команды сборки,
тестов и правила ревью. Из зависимостей установщику нужен Python 3.12+.

## Подключение

```sh
python templates/dev-agent-team/install.py /path/to/project --profile backend
python templates/dev-agent-team/install.py /path/to/project --profile backend --apply
python templates/dev-agent-team/install.py /path/to/project --check
```

Первая команда показывает diff. Профиль `backend` включает ТАЙГУ, МАЯКА, ИСКРУ
и КОНТУРА. Профиль `ui` дополнительно включает РУБИНА. ПРОГРЕСС — основной
чат. Доступность делегирования и выбор модели активного чата определяет клиент.

Установщик создаёт проектные TOML агентов, добавляет управляемый блок в
`AGENTS.md` и записывает локальные настройки в `.codex/dev-team.toml`.
Если `.codex/config.toml` отсутствует, добавляется проектное значение по
умолчанию для модели ПРОГРЕССА и лимита специалистов. Существующий
отличающийся конфиг берётся как локальный и сохраняется побайтно.

## Настройка проекта

```toml
profile = "ui"
parallelism = 2

[roles.reviewer]
model = "gpt-6.2-astra"
model_reasoning_effort = "high"

[roles.designer]
callsign = "ДИЗАЙНЕР"

[roles.librarian]
enabled = false
```

После правки настроек повторно выполните `--apply`. Начальный `--profile`
используется только при первом запуске. Язык, архитектура, MCP, CodeGraph,
команды проверок и разрешения рабочего окружения задаются проектом.
Роль `primary` позволяет выбрать имя, модель и reasoning основного чата.
Для уже существующего локального конфига значение модели там меняется
вручную с учётом настроек клиента.

## Обновление и конфликты

`.codex/dev-team-state.json` хранит версию и контрольные суммы сгенерированных
файлов и блока. Храните его рядом с профилями проекта. При обновлении шаблон
заменяет сохранённые без локальных изменений файлы и блок. Остальной
`AGENTS.md`, чужие агенты и настройки проекта сохраняются. Если сгенерированный
файл роли или сам блок редактировались вручную либо имя роли занято, установщик
покажет конфликт и приостановит применение. Для изменения роли используйте
`.codex/dev-team.toml`. У `--check` код 1 означает расхождение или конфликт,
код 2 означает ошибку чтения, конфигурации или записи.

Скилл распространяется вместе с автономной копией комплекта. Его исходник
находится в `skill/dev-team-onboarding/SKILL.md`. Чтобы установить его в
личный каталог Codex, передайте путь к используемому клиентом каталогу скиллов.

```sh
python templates/dev-agent-team/install-skill.py /path/to/skills
```

Из чата целевого проекта вызовите `$dev-team-onboarding` и попросите его подключить
команду. Проверить установленный набор можно в новом проектном сеансе Codex.
