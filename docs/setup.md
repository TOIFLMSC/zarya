# Установка

## Окружение

Python 3.12 (ограничение pyproject.toml), uv, Node.js 24, pnpm 11.19.0.
Python — сервер и фоновые задачи; Node.js нужен только для сборки UI.
Установка: `uv sync --frozen`, затем в `web` — `pnpm install --frozen-lockfile`
и `pnpm run build`. Не удаляйте lock-файлы для обхода ошибок зависимостей.

Создайте папку `data` и скопируйте `src/zarya/prompts.example.json` в
`data/prompts.json`, только если собственного файла ещё нет. Это нейтральная
конфигурация; задайте собственный характер через UI. На Linux используйте
`mkdir -p data` и `cp -n src/zarya/prompts.example.json data/prompts.json`.

Запуск из корня: `uv run --frozen zarya`. Windows с подготовленной .venv:
`./start.ps1`. Остановка: Ctrl+C. Один процесс, один Uvicorn worker, без reload.
Первый запуск создаёт БД и bootstrap-token.txt; локальная панель —
http://127.0.0.1:8787. Ключ начальной настройки удаляется после создания
администратора; в БД сохраняется хеш пароля. Удаление БД не является сбросом пароля:
это удаление настроек, доступов, памяти и очередей.

## Подключения

В файлы одной строкой: `data/telegram-token.txt` и `data/openai-api-key.txt`.
Альтернатива — переменные `ZARYA_TELEGRAM_TOKEN` и `OPENAI_API_KEY` (приоритет
над файлами). `.env` автоматически не читается; `.env.example` — справочник.
После изменения ключей нужен перезапуск.

В Telegram создайте отдельного бота через BotFather. Отправьте ему `/start`,
одобрите заявку в «Telegram и доступ». Для группы добавьте бота и разрешите
группу в UI. Для обычного контекста группы Telegram должен передавать сообщения:
проверьте Privacy Mode и права бота. Включение группы не одобряет личку участников.
В настройках задайте Telegram ID владельца; username сам по себе прав не даёт.

Установите FFmpeg/ffprobe для голоса и видео. На Windows доступен
`scripts/setup-media.ps1`: архив проверяется по закреплённому SHA-256; если
upstream изменился, скрипт остановится. Не отключайте проверку хеша. Можно
установить бинарники самостоятельно и указать ZARYA_FFMPEG/ZARYA_FFPROBE либо PATH.

Проверьте сначала личку, обращение по имени в группе, реплай, фото и короткое
голосовое. Используйте журнал UI для ошибок провайдера и доставки. Автотесты
работают на синтетических адаптерах и не подтверждают живое подключение.
