# Приватные данные и публикация

В Git входят исходники, тесты с синтетическими данными, нейтральный пример
промптов, lock-файлы и эта документация. `.gitignore` исключает data, backups,
restore-checks, logs, окружения, сборки, результаты тестов, .env и локальные
agent-конфигурации. Исторические заметки конкретной установки исключены отдельно.

Приватны: SQLite/WAL/SHM, настройки и их версии, промпты, диалоги и снимки запросов,
профили/память, согласия/доступы, исходные медиа, диагностические выгрузки,
ключи и резервные копии. Резервная копия — не обезличенный экспорт.
Не помещайте реальные значения в .env.example, prompts.example.json, фикстуры,
скриншоты, issue или PR. При публичной демонстрации используйте отдельную пустую БД.

Перед коммитом:

```powershell
git status --short
git diff --cached --stat
uv run --frozen python scripts/check-publication.py
```

Проверка читает именно Git index, отклоняет неожиданные пути/базы/архивы и типичные
форматы ключей. Читает локальный файл промптов, SQL-выпуски и черновики конфигурации,
ищет длинные частные фрагменты
в подготовленных текстах, включая экранированные Python/JSON-строки. Пути берутся
из ZARYA_DATA_DIR и ZARYA_PROMPTS_FILE либо стандартного data. Это дополнительная
проверка, а не математическая гарантия отсутствия всех секретов. Ручное ревью остаётся
необходимым. .gitignore не удаляет уже закоммиченные данные, а `git add -f` обходит его.
Если секрет попал в историю, сначала отзовите его; удаления из последнего коммита мало.

Клиенты Telegram/OpenAI получают данные, необходимые для выполнения запросов.
Локальное хранение не означает, что модель работает офлайн. Ограничивайте доступы
чатов и локальный доступ к панели и файлам по своей модели угроз.

Подключённая папка Obsidian содержит приватную память групп и одобренных личных
переписок. Если папка входит в Obsidian Sync, её файлы синхронизируются настройками
этого сервиса. Приложение очищает только управляемые локальные заметки; отдельные
копии, версии Sync и корзины требуют самостоятельного удаления. База и API-ключи
в папку не экспортируются. Синхронизация для владельца не меняет права участников
и не разрешает перенос личных сведений в группы.

Подпапка `Конфигурация Зари` содержит полный приватный характер, сведения
о владельце, настройки моделей/глобального поведения и инструкции. При включённом
Sync они синхронизируются вместе с остальным vault; подключайте только разрешённую
приватную папку. SQL хранит историю выпусков и черновики. Удаление заметки не удаляет
эту историю, резервные копии или версии Sync. API-ключи и права чатов не экспортируются.

CodeGraph читает только разрешённые исходники, тесты и публичные технические
документы. Индекс хранит пути, идентификаторы, позиции, хеши и структурные связи;
тела функций, комментарии, строковые значения и текст документов в него не входят.
Закрытые папки, исторические заметки, SQLite и настройки установки не читаются.
Индекс в data/codegraph исключён из Git. Подпапка `CodeGraph Зари` содержит такую
же структурную карту и может попадать в Sync по настройкам vault. Это не проверка
публикации: аудит Git index выполняется отдельно командой выше.

Индекс E5 хранит векторы в памяти процесса. Модель получает тексты для
кодирования локально. Перед выдачей записи действующие разрешения и версия
проверяются в SQLite. В резервные копии индекс не включается.

Для [состояния задачи](task-state.md) модель памяти OpenAI получает ограниченный
набор связанных принятых реплик. Сводка и ссылки на ревизии хранятся в SQLite
и входят в резервную копию базы. Исходный запрос фонового извлечения в журнале
вызовов не сохраняется. Сводки не экспортируются в Obsidian и не передаются
во внешний поиск.
