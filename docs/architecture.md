# Архитектура

FastAPI/Uvicorn обслуживает авторизованный UI и один supervised lifespan.
aiogram получает Telegram updates; SQLite WAL хранит inbox, jobs, outbox,
смещения получения, версии настроек, доступы, память и учёт запросов к моделям.
Транзакции сериализованы; задача asyncio не заменяет долговечную очередь.

Маршруты разделены: DialogueEngine формирует ответ, PhotoEngine анализирует
фото, MediaEngine готовит речь/кадры через FFmpeg и модель, AvatarEngine работает
с выбранным профилем, MemoryEngine извлекает факты/сводки, ResearchEngine получает
публичные материалы. Общий неизменяемый PromptBundle передаётся через TelegramStore.
Официальный OpenAI adapter обслуживает Responses и ASR; модели и глубина выбираются
по маршрутам. Реальные секреты приходят только из локальной конфигурации.

Контекст ограничен. Память групп общая для их топиков; разные группы разделены.
Личные разговоры изолированы. Перенос личных сведений требует согласия участника;
владелец панели может исправить запись, но не выдать такое согласие за него.
Контекст хранится до 90 дней, факты — до удаления с переоценкой. Зависимости
проверяются при извлечении, генерации, replay и доставке. Отзыв/удаление источника
не должен оставлять его данные в производных ответах.

Цепочки реплаев связываются с выбранным исходным постом и отправленными сообщениями
бота. Они не подменяются последним фото чата. Поиск получает ограниченный публичный
запрос, без личной памяти и недавней переписки. Содержимое страниц, медиа и сообщений
считается данными, не инструкцией изменить права или настройки.

Неопределённый результат платного вызова автоматически не повторяется.
Повторная доставка ограничена состоянием outbox и ошибкой транспорта. Локальный
журнал хранит запросы, ответы, причины решений и usage; скрытые рассуждения модели
не являются доступным пользовательским журналом.

Сборка UI раздаётся Python-сервером; отдельный Node.js backend не нужен.
Миграции: src/zarya/migrations, зависимости: uv.lock и web/pnpm-lock.yaml.
