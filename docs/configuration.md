# Конфигурация

## Где хранится

| Что | Источник | Как менять |
| --- | --- | --- |
| Характер, имя, тон, владелец, модели и лимиты | data/zarya.sqlite3 | Настройки Web UI |
| Реакции, выразительность, режим/шанс инициативы | SQLite | Поведение |
| Разрешения, память, журнал | SQLite и media-файлы в data | Соответствующие разделы UI |
| Полные инструкции всех модельных маршрутов | data/prompts.json | Локальный текстовый редактор, затем перезапуск |
| Ключи API | Файлы в data либо окружение | Локально, затем перезапуск |
| Пути, порт, медиабинарники | Окружение | .env.example описывает имена |

`ZARYA_DATA_DIR` переносит всё хранилище; `ZARYA_PROMPTS_FILE` задаёт отдельный
приватный файл инструкций. Любые каталоги за пределами проекта защищайте отдельно:
.gitignore действует только в своём репозитории. `ZARYA_WEB_DIR` задаёт сборку UI,
`ZARYA_PORT` — локальный порт. `ZARYA_DEV_UI=1` отключает реальные интеграции
и разрешает локальный Vite origin для разработки.

## Пакет промптов

JSON с `schema_version: 1` и объектом `fragments`. Полный набор ключей задан
в нейтральном `src/zarya/prompts.example.json`: dialogue.*, links.*, behavior.plan,
memory.extract, research.analyse, media.*. Значения — текст, не Python/Jinja:
скобки и выражения не исполняются. Динамические имя, persona и тон подставляет
сам код в фиксированных местах. Не удаляйте обязательные ключи.

Пакет ограничен 128 КиБ, фрагмент — 32768 символов. Повторные/неизвестные ключи,
неверная версия и типы отклоняются. Обычный CLI-запуск требует локальный файл;
отсутствие или ошибка не подменяются публичным примером. Программный Config без
prompts_file использует нейтральный пакет для тестовых/встроенных установок.

Файл загружается единожды до запуска клиентов. Все движки используют один пакет.
Для изменения остановите приложение, отредактируйте файл, запустите снова.
Настройки через UI применяются к новым операциям без рестарта; уже начатые
операции используют зафиксированный снимок. Сохранённый replay не вызывает модель;
платный replay использует текущие настройки и пакет. Снимки могут содержать полный
промпт, поэтому база и выгруженные журналы приватны.

Схемы ответа, права доступа, разделение памяти, ограничения файлов, сетевые
проверки и правила очередей остаются кодом. Текст промпта не заменяет эти проверки.
Публичные значения по умолчанию — пример новой установки, а не экспорт настроек
какого-либо работающего бота. Старые версии настроек в существующей БД сохраняются.
